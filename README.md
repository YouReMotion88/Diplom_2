# Дипломный проект: тестирование API Stellar Burgers

## Описание проекта

Проект посвящён автоматизации тестирования API сервиса Stellar Burgers.

В рамках проекта реализованы автотесты для проверки основных функций API.

## Используемые технологии

- Python
- Pytest
- Requests
- Allure Pytest

## Проверяемые функциональности

- Создание пользователя.
- Проверка регистрации пользователя с некорректными данными.
- Авторизация пользователя.
- Проверка авторизации с некорректными данными.
- Изменение данных пользователя.
- Создание заказа с авторизацией и без неё.
- Создание заказа с ингредиентами и проверка обработки некорректных ингредиентов.
- Получение списка ингредиентов.

## Запуск тестов

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить тесты с формированием результатов Allure:

```bash
pytest --alluredir=allure_results
```

Для просмотра отчёта Allure:

```bash
allure serve allure_results
```
